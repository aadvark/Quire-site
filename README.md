<h1 align="center">Quire</h1>

<p align="center">
  <strong>Any website, as a magazine.</strong> A calm magazine reader for Android.<br>
  <a href="https://aadvark.github.io/Quire-site/">Visit the website</a> ·
  <a href="https://github.com/aadvark/Quire-site/releases/latest/download/quire.apk">Download the APK</a> ·
  <a href="https://aadvark.github.io/Quire-site/privacy.html">Privacy policy</a>
</p>

Paste the address of a site you love. Quire finds its articles and lays them out as pages
you turn. Make your own magazines with a title and a cover. Free for Android 8.0 and
newer, with no ads, no account and no tracking. Quire checks for new versions itself, so
you only install once.

Made in Singapore by Lee Wen Yang (Mike).

## About this repo

This public repo holds the [landing page](https://aadvark.github.io/Quire-site/), served
by GitHub Pages from `main`, and the APK downloads under
[Releases](https://github.com/aadvark/Quire-site/releases). The app's source code is
private and lives elsewhere; nothing from it belongs here.
